# Maine Autumn Sunset — Omarchy theme

![Maine Autumn Sunset preview](preview.jpg)

## Install

```
omarchy-theme-install https://github.com/lutzlstein/omarchy-maine-autumn-sunset-theme
```

Aether (adds it to your blueprints and applies it):

```
aether --import-blueprint https://raw.githubusercontent.com/lutzlstein/omarchy-maine-autumn-sunset-theme/main/blueprint.json --auto-apply
```
